# 1d-fluid-convection-solver
# 1D Steady-State Convection-Diffusion Solver

A finite difference numerical solver written in Python to compute the 1D steady-state temperature profile in a moving fluid medium subjected to thermal advection and diffusion.

## Mathematical Formulation

The governing continuous 1D advection-diffusion equation is defined as:

$$u \frac{dT}{dx} = \alpha \frac{d^2T}{dx^2}$$

Where:
* $u$ = Fluid transport velocity ($\text{m/s}$)
* $\alpha$ = Thermal diffusivity ($\text{m}^2/\text{s}$)
* $T$ = Temperature field ($\text{°C}$)

### Numerical Scheme
The domain is discretized into $N$ grid points using standard second-order central difference approximations for both first and second-order spatial derivatives:

$$\frac{dT}{dx} \approx \frac{T_{i+1} - T_{i-1}}{2\Delta x}$$

$$\frac{d^2T}{dx^2} \approx \frac{T_{i+1} - 2T_i + T_{i-1}}{\Delta x^2}$$

The resulting linear system $A T = b$ is solved using NumPy's dense linear algebra solver package (`numpy.linalg.solve`).
